# Store-Badges

Die **offiziellen** Badges von Apple und Google. Uebernommen aus
anigosha/tools/reels/spot/badges/ — dort steht die ausfuehrliche Fassung
dieser Regeln.

| Datei | |
|---|---|
| `appstore-en.png` | „Download on the App Store" |
| `googleplay-en.png` | „GET IT ON Google Play" |

Beide 1000x335, Verhaeltnis 3:1 — sie stehen deshalb sauber nebeneinander.

⚠ **Nicht nachzeichnen, nicht verzerren, nicht einfaerben.** Apple und Google
geben Form, Farbe und Mindestabstand vor; ein veraenderter Badge ist ein
Markenverstoss. Wer sie tauscht, nimmt die Originaldateien aus den
Marketing-Ressourcen der beiden Anbieter.

⚠ **Nur zeigen, was es wirklich gibt.** Steht eine Plattform nicht im Store,
gehoert ihr Badge nicht auf den Post. Die Wahrheit dazu steht in `STORES`
in post-bild.mjs und post-reel.mjs.
